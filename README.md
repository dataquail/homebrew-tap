# dataquail/homebrew-tap

Homebrew formulae for dataquail's tools.

```bash
brew install dataquail/tap/chernabog
```

| Formula | Source |
| --- | --- |
| `chernabog` | [dataquail/chernabog](https://github.com/dataquail/chernabog) |

The formulae are written by each project's release workflow; changes made here by hand are overwritten by the next release.
